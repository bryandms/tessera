# Releases

The current version is <strong>v{packageJson.version}</strong>.

Each release is a Git tag named `v{version}`. Versions follow [Semantic Versioning](/#versions), so a minor or patch release keeps your copy working and a major release can require changes.

## Where to find the changes

- [Changelog](https://github.com/bryandms/tessera/blob/main/CHANGELOG.md): every change, grouped by release.
- [GitHub releases](https://github.com/bryandms/tessera/releases): release notes with the commits of each tag.
- [Tags](https://github.com/bryandms/tessera/tags): every version of the repository.

## Read the documentation of a release

This site shows the documentation of the `main` branch. To read the documentation of an older release, open its tag in the repository, for example `https://github.com/bryandms/tessera/tree/v0.1.0/apps/website/docs`.
