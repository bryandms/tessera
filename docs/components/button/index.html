Button

The button component is the interactive anchor of the catalog: three appearance variants (contained, outlined, text) × two color axes (primary, secondary), three sizes and additive pieces (Icon, Text) that share the root state through an internal context. Copy it into your project — no package to install.

To copy Button into your project, follow the How to copy guide — copy core once plus the button folder, mount ThemeProvider and you are done.

import { StyleSheet, View } from 'react-native';
import { Button } from 'tessera';

export function ButtonBasicExample() {
  return (
    <View style={styles.container}>
      <Button.Root onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    gap: 8,
  },
});

Examples​

Variants​

Two independent axes: variant decides the appearance (contained fill, outlined border, text borderless) and color decides the palette family (primary, secondary) — no props mirror between the root and its pieces:

import { StyleSheet, View } from 'react-native';
import { Button } from 'tessera';

export function ButtonVariantsExample() {
  return (
    <View style={styles.container}>
      <Button.Root variant="contained" color="primary" onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
      <Button.Root variant="outlined" color="primary" onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
      <Button.Root variant="text" color="primary" onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
      <Button.Root variant="contained" color="secondary" onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
      <Button.Root variant="outlined" color="secondary" onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    gap: 8,
  },
});

With icon​

Button.Icon is marked decorative for screen readers (importantForAccessibility="no" + accessibilityElementsHidden), so the accessible name comes from Button.Text only; the icon inherits the variant color automatically:

import { StyleSheet, Text, View } from 'react-native';
import { Button } from 'tessera';

export function ButtonWithIconExample() {
  return (
    <View style={styles.container}>
      <Button.Root onPress={() => {}}>
        <Button.Icon>
          <Text style={styles.icon}>{'+'}</Text>
        </Button.Icon>
        <Button.Text>Label</Button.Text>
      </Button.Root>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    gap: 8,
  },
  icon: {
    fontSize: 16,
    lineHeight: 20,
  },
});

Full width​

By default the root hugs its content. Full-width buttons (form footers, sheet actions) configure themselves through the style prop — no dedicated prop needed:

import { StyleSheet, View } from 'react-native';
import { Button } from 'tessera';

export function ButtonFullWidthExample() {
  return (
    <View style={styles.container}>
      <Button.Root style={{ alignSelf: 'stretch' }} onPress={() => {}}>
        <Button.Text>Label</Button.Text>
      </Button.Root>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    gap: 8,

Style override​

The style prop is the escape hatch: plain RN styles or (theme, state) => styles (the function receives pressed, disabled and busy) — here it turns the base into a "Tip" pill with a press animation, without touching the component or adding variants:

import { StyleSheet, Text, View } from 'react-native';
import { Button } from 'tessera';

export function ButtonStyleOverrideExample() {
  return (
    <View style={styles.container}>
      <Button.Root
        variant="outlined"
        color="secondary"
        onPress={() => {}}
        style={(theme, { pressed }) => ({
          borderRadius: theme.radius.full,
          borderWidth: 2,
          borderColor: theme.palette.warning.textColor,
          backgroundColor: theme.palette.common.white,
          transform: pressed ? [{ scale: 0.96 }] : [],
        })}>
        <Button.Icon>
          <Text style={styles.icon}>{'$'}</Text>
        </Button.Icon>
        <Button.Text>Tip</Button.Text>
      </Button.Root>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    gap: 8,
  },
  icon: {
    fontSize: 16,
    lineHeight: 20,
  },
});

Accessibility​

What the component sets for you:

  • accessibilityRole="button" and accessibilityState={{ disabled, busy }} on the root — states come from the props, never duplicated in the label.
  • The Icon piece is hidden from assistive tech, so the accessible name is the text piece.
  • Touch target: the default md size keeps ≥ 48dp; sm is the compact exception (36dp), lg grows to 56dp.

What you should provide:

  • A Button.Text child with a meaningful action label (verbs, not "OK").
  • onPress — the component does not simulate actions without it.
  • busy={true} while an action is pending; the state is announced and visual styles keep the disabled look if you pair it with disabled.

The rendered root is a flattened style, so it composes safely with Link asChild wrappers when the action is navigation. Default sizing: the root hugs its content (row direction, centered label) — make it full width with style={{ alignSelf: 'stretch' }}.

Dependencies​

Everything this component imports, so you can estimate the effort of porting fixes:

ImportWhy
react-native (Pressable, Text, StyleSheet, types)Primitives being wrapped
../../core (createVariants, resolveTesseraStyle, useTheme, types)Theme access, variants typing, theme-aware style

Tokens consumed from your copied core: palette.primary/secondary (fills, borders, labels per variant), palette.action.disabled* (states), the button type scale (labels) and the spacing/radius scales (shapes). Editing those tokens restyles every instance globally — no component changes needed.

No other component is imported — fixes port as a file-level diff against your copied folder (button.tsx, button-context.ts, types.ts, variants.ts, index.ts).

Props API​

Button.Root (the interactive piece):

PropTypeDefaultDescription
variantButtonVariant'contained''contained' (filled), 'outlined' (bordered), 'text' (borderless)
colorButtonColor'primary'Palette family: 'primary' (blue), 'secondary' (gray)
sizeButtonSize'md''sm', 'md', 'lg' — visual scale in heights (36/48/56); the default keeps a ≥ 48dp touch target
disabledbooleanfalseCancels interaction, muted state announced
busybooleanfalseAnnounced through accessibilityState (pair with your own pending UI)
styleTesseraStyleProp<ViewStyle, ButtonState>—Plain RN styles or (theme, { pressed, disabled, busy }) => styles, applied last
onPress, testID, …PressableProps—Forwarded untouched

Button.Text and Button.Icon do not take variant props — they inherit from the enclosing root; forward extra Text props as needed.
